# Generated OpenAPI TS types

This directory is generated by `npm run generate:api-client` (wraps
`openapi-typescript`) from `frontend/openapi.json`, which is itself a
snapshot of the backend's `/openapi.json`. Do not hand-edit `schema.d.ts`.

CI regenerates this against a live backend instance and fails the build if
the regenerated output differs from what's committed (drift check) — see
`.github/workflows/ci.yml`.
